📊 Heart Disease Exploratory Data Analysis (EDA)

This project explores a heart disease dataset using Python to identify key factors influencing heart disease. The goal is to perform data cleaning, statistical analysis, and visualization to extract meaningful insights.

🔍 Key Objectives:
- Understand dataset structure
- Perform data cleaning and preprocessing
- Identify missing values and outliers
- Analyze relationships between features
- Visualize trends using graphs and charts
- Extract insights for medical understanding

📈 Techniques Used:
- Data Cleaning & Preprocessing
- Statistical Summary
- Correlation Analysis
- Data Visualization (Matplotlib & Seaborn)
- Feature Exploration

📊 Key Insights:
- Age group 40–60 shows higher risk of heart disease
- Chest pain type is a strong indicator of disease
- Maximum heart rate is lower in affected individuals
- Cholesterol contains noticeable outliers

🛠️ Tools & Libraries:
Python, Pandas, NumPy, Matplotlib, Seaborn

📁 Dataset:
Heart Disease Dataset (Kaggle)

🎯 Outcome:
Gained insights into factors influencing heart disease and improved data analysis skills using real-world medical data.
